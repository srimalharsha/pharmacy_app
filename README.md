# ChannelMed Manager

A fresh pharmacy-management application project for Android and Web.

## Current stage
The first responsive dashboard preview is a **UI prototype** with sample/demo data. It is not connected to a live pharmacy database, authentication, billing hardware, or real medicine records yet.

## Preview
After GitHub Pages is enabled for this repository, the web preview will be available at:
https://srimalharsha.github.io/pharmacy_app/

## Planned modules
- Pharmacy accounts with strict data separation
- Owner and staff roles
- Medicine inventory, batch and expiry tracking
- Barcode-based billing and invoices
- Suppliers and purchase records
- Customers, sales and profit reports
- Low-stock and expiry alerts

## Important
All figures and medicine records currently shown are fictional demo data. Do not use this prototype for real dispensing, inventory, or financial decisions.
